# Local Link's Agents

Local Link provides four ready-made agents in `ready-made/`, examples to
start from, build on, and share. Each is an archive kept as a folder,
with a README beside its `archive.toml`, which you import and start.

- [Ready-Made Agents](../modules/agents/agent/docs/agents/ready-made/README.md): what each comes with, how far it goes, and how to start it
- [scripts/pack.sh](scripts/pack.sh): packs and imports each, as a release does
