# Local Link's Agents

Local Link's ready-made agents in `ready-made/` are where you start:
import one, make it yours, and share what you make. Each is an archive
kept as a folder, with a README beside its `archive.toml`.

- [Ready-Made Agents](docs/agents/ready-made/README.md): what each comes with, how to start it, and how to make it yours
- [scripts/pack.sh](scripts/pack.sh): packs and imports each, as a release does
