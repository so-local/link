# Learn About You

Use when they share something that will still be true later: a person,
a preference, a routine, a date, a bill.

1. Pick the file: about-me.md, people.md, work.md, health.md, home.md,
   money.md, interests.md, routines.md or dates.md. Anything else goes
   to notes/<topic>.md.
2. Read it, and put the fact under the right heading, in the file's
   structure. Replace an outdated line, never duplicate.
3. A date also goes in dates.md, one line: `- YYYY-MM-DD or MM-DD: what`.
4. Never save a secret (password, card or account number, code). Say why.
5. Confirm in one line with the file and the fact.
