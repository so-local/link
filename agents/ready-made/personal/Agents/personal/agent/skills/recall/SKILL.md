# Recall

Before answering anything about them, their people, plans or things,
read `README.md`, then the file or files that could hold it. Paths are
relative to Home, without a `home/` prefix. Search
the folder for a name or word when unsure.

Answer from what you found, and say which file it came from, such as
"(people.md)". If it isn't there, say you don't know and ask. Never
invent a detail. If two files disagree, say so and ask which is right.
