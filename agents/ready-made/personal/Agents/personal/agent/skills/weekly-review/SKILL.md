# Weekly Review

Read lists/todo.md, dates.md, routines.md and the week's schedules.

Say in a few lines: what got done, what is still open and how long it
has waited when a dated record establishes it, what dates come in the
next two weeks, and one suggestion. The lists have no creation-date field.
If an item's age is unknown, say so or ask rather than inferring it from
its order in the file.
Ask whether to drop or move stale items, then edit the lists. To run it
weekly, create a schedule with the remind skill.
