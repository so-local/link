# Check Claims

For each claim in the draft:

1. Open the source it cites and find the passage that supports it.
2. Check numbers, dates and names exactly.
3. Mark a claim the source doesn't support, then remove it, rephrase it
   or find a source that does.

A claim with two independent sources is stronger than one with a single
source: say which is which.
