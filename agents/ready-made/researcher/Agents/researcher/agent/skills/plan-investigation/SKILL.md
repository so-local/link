# Plan an Investigation

Before reading or searching, write down:

- **The question,** in one sentence, and the smaller questions that
  answer it.
- **Where to look:** primary sources first, such as official sites,
  papers, standards and data, then reputable reporting.
- **Done when:** what the report must answer, and what is out of scope.

Revise the plan when a source changes what you thought the question was.
