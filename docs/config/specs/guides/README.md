# Specification Guides

> Configure a Resource From Its Owning Rules

Specification guides explain how each resource's specification fits together. The
[Agent Specification Guide](../../../../modules/agents/agent/contract/spec/docs/config/specs/guides/agent.md)
explains composition, [Features](../../../../modules/agents/agent/contract/spec/docs/config/specs/guides/features.md)
explains the behaviors an agent can enable, and
[Schedule Definitions](../../../../modules/agents/agent/contract/spec/docs/config/specs/guides/schedules.md)
explains when an agent runs. The [Team Specification Guide](../../../../modules/agents/agent/contract/team/docs/agents/more/interface/contract/team.md)
connects a team's definitions to its roster.

## Services and Permissions

The [Box Specification Guide](../../../../modules/compute/box/docs/config/specs/guides/box.md)
explains machine selection. The [Sandbox Specification Guide](../../../../modules/security/sandbox/docs/config/specs/guides/sandbox.md)
explains confinement, and the [Policy Specification Guide](../../../../packages/policy/docs/config/specs/guides/policy.md)
explains actions, resources, and limits. Each guide links to the complete
field reference rather than copying the format.
