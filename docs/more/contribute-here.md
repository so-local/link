# Contribute Here

Here's where we'd love your help. Each item below is something Local Link already does that a contribution would make better, linked to the section that says how.

## How to Pick Something

Read an item's section on its own page first. It says what the feature
does today, where it stops, and what a contribution adds. For anything
bigger than a fix, open an issue to talk it through before you write
it, then follow [Send a Change](README.md#send-a-change) to build, test
and open a pull request.

## How Items Get Here

Every item is a Contribute Here section on the page of the feature it
asks for, written once beside that feature. The docs inventories gather
each one here as its page's title and first sentence, so this list is
never edited by hand and never says anything twice.

Each item names its page and the first sentence of its section.
