# Maintain Documentation

> Explain Behavior and Keep It Current

Begin with the reader's task and verify each claim against the owning
implementation. The editorial workflow is in
[Writing Docs](../../../../tests/docs/docs/more/developing/documentation/writing-docs.md),
and the checks that hold it are in
[Docs Rules](../../../../tests/docs/docs/more/developing/documentation/docs-rules.md).

## Keep Reading Paths Working

Generated indexes and site outlines are explained in
[Documentation Navigation](../../../../tests/docs/docs/more/developing/documentation/navigation.md).
The short headings that section pages use are in
[Writing Hooks](../../../../tests/docs/docs/more/developing/documentation/hooks.md).

## Check Documented Examples

[Docs Code Checks](../../../../tests/docs/code/docs/more/developing/documentation/checks.md)
checks documented examples and declarations
against the actual readers. Use these checks alongside the editorial rules when a
command or configuration format changes.
