# Set Up Development

> Prepare a Checkout and Its Tools

Prepare a checkout and its tools. [Install from Source](install.md) prepares the
executable and its modules, and
[Development Environment](agents.md) explains
the available coding environments. Use
[Developer Boxes](../../../../scripts/docs/more/developing/setup/dev-boxes.md)
when the work needs a remote development machine.

## Follow Coding Conventions

Follow the shared coding rules in [Conventions](conventions.md). Apply those rules to the component being changed, then
choose checks that fit the actual machine and change.
