# Command Index

Find the commands declared by the core and registered modules. Each
link opens its owning declaration; use the command's help for its
arguments and the feature's documentation for a worked example.

## Registered commands

This inventory includes command prefixes routed by `lnk`, internal
commands beneath those prefixes, and the core's own declarations.
Replaced commands and a module's standalone program interface are
excluded. Modules installed from outside this repository declare their
own commands.
