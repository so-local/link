# Interoperability

Local Link works with other projects' products through adapters. Each
adapter fits one product, such as the OpenClaw harness, Slack, or Amazon
Web Services, to the same `lnk` commands you already use.

## Docs

- [Agent Adapters](agents/README.md): Agent adapters connect your agent to other projects' harnesses and chat apps
- [Cloud Adapters](cloud/README.md): Cloud adapters let Local Link make buckets and boxes in your own cloud account
