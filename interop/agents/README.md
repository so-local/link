# Agent Adapters

Agent adapters connect your agent to other projects' harnesses and chat
apps. Each adapter is a module you install.

## Docs

- [Connections](connections/README.md): Connections are the chat apps your agent answers you on
- [Harnesses](harnesses/README.md): Harness adapters let Local Link install, configure, and run other projects' agent harnesses
