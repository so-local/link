# Connections

Connections are the chat apps your agent answers you on. Each app is a
connection module you install.

<!-- docs-tree:start -->

## Docs

- [Discord for Link](discord/README.md): The Discord connection, `lnk-discord`, lets your agent answer you in Discord
- [Signal for Link](signal/README.md): The Signal connection, `lnk-signal`, lets your agent answer you in Signal
- [Slack for Link](slack/README.md): The Slack connection, `lnk-slack`, lets your agent answer you in Slack
- [Telegram for Link](telegram/README.md): The Telegram connection, `lnk-telegram`, lets your agent answer you in Telegram
