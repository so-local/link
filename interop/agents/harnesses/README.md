# Harnesses

Harness adapters let Local Link install, configure, and run other
projects' agent harnesses. Each adapter is a module you install.

## Docs

### Pages

- [Compare Harnesses](docs/agents/harnesses/compare.md): Compare the harnesses Link can create and control, the existing installations it can adopt, and the state each adapter can transfer
- [Harness Adapters](docs/agents/harnesses/adapters/README.md): Run a third-party harness through Local Link's agent commands, with your model, files, tools, and messaging connections

### Modules

- [DeepSeek Harness for Link](deepseek/README.md): The DeepSeek Harness adapter, `lnk-deepseek`, lets Local Link install, sandbox, and run DeepSeek Harness (`dsh`)
- [Hermes Agent for Link](hermes/README.md): The Hermes Agent adapter, `lnk-hermes`, lets Local Link install, sandbox, and run Hermes Agent
- [OpenClaw for Link](openclaw/README.md): The OpenClaw adapter, `lnk-openclaw`, lets Local Link install, sandbox, and run OpenClaw

### More
