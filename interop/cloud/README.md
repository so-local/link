# Cloud Adapters

Cloud adapters let Local Link make buckets and boxes in your own cloud
account. The `lnk cloud` and `lnk box` commands use one for each account
you connect.

<!-- docs-tree:start -->

## Docs

- [Amazon Web Services](aws/README.md): The AWS adapter, `lnk-aws`, manages accounts, buckets, and boxes on Amazon Web Services through the `aws` CLI
- [Google Cloud](gcp/README.md): The Google Cloud adapter, `lnk-gcp`, manages accounts, buckets, boxes, and images on Google Cloud through gcloud
