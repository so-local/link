# Modules

Modules are the programs Local Link installs and runs. Each module is an
executable that `lnk` runs for its commands, and the modules are grouped by
domain.

<!-- docs-tree:start -->

## Docs

- [Agents](agents/README.md): Agents holds everything that runs an agent in Local Link
- [Cloud](cloud/README.md): Cloud connects your cloud accounts once, so Local Link's buckets and boxes can use them
- [Compute](compute/README.md): Compute holds the modules that give your agents machines
- [Security](security/README.md): Local Link keeps your secrets and runs every program in a sandbox
- [Storage](storage/README.md): Storage backs up your folders to your own clouds, and frees space here once the copies are safe
- [Tooling](tooling/README.md): Tooling holds the modules that run around your agents
