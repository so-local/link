# Harnesses

Harnesses are the programs that run your agents. Local Link comes with Link Harness and Mini Harness, and with the portability packages that every harness shares.

### Modules

- [Link Harness](link/README.md): Link Harness, `lnk-harness`, is Local Link's own harness, run like any other
- [Mini Harness](mini/README.md): Mini Harness is a small persistent, tool-using agent built on Local Link's model and tool interfaces
