---
Your owner asked you to learn from this conversation: keep what you just
did as a skill, so the next time a task like it comes, you do it well
from the start.

A skill is a folder of `skills/`, `skills/<name>/`, its instructions in
`SKILL.md`: a line `---`, `name: <name>`, `description: <what it's for,
one line>`, a line `---`, then the instructions themselves. Its name is
lowercase letters, digits and `-`.

First decide which it is:

- a skill you followed that misled you: fix that one, keeping what was
  right in it;
- a skill like it you have already: add to that one;
- else, a new one, named for the kind of task.

Then write it with the file tool (`file__write`, `file_path`
`skills/<name>/SKILL.md`), short, in plain words: when it applies, the
steps that worked, in order, and what went wrong and how to avoid it.
Keep facts about this one task, your owner and their files out: a
skill is for the next task like it, and they belong in your notes.

Last, say in a line or two which skill you wrote or fixed, and why.
