# Desktop Tool Command Line

`link-desktop-tool-contract` gives the callers of `lnk-desktop-tool` its
runtime arguments as types, `CookieCreateArgs` and
`DesktopToolServeArgs`, and the command line each one's `argv` writes,
generated from the tool's `actions.toml`, as the parser the tool reads
it with is. The agent module builds both; a display is a whole number.
