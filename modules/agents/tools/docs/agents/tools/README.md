# Tools

> Tools for Browsing, Coding, and More

Tools let your agent work with files, programs, web pages, and screens,
keep searchable memory, and delegate or schedule work. Choose the
providers your tasks need, then grant their access through your agent.

## Work with Files and Code

[File](../../../file-tool/docs/agents/tools/file/README.md) reads and edits granted files, [Run](../../../run-tool/docs/agents/tools/run/README.md) executes allowed programs, such as [Python and JavaScript scripts](../../../run-tool/docs/agents/tools/run/scripts.md), and [Code](../../../code-tool/docs/agents/tools/code/README.md) asks language servers for diagnostics and symbol locations.

## Work with Pages and Screens

[Web](../../../web-tool/docs/agents/tools/web/README.md) fetches text and searches with your credential. [Browser](../../../browser-tool/docs/agents/tools/browser/README.md) interacts with pages on Linux, while [Desktop](../../../desktop-tool/docs/agents/tools/desktop/README.md) works with a Linux virtual screen.

## Remember and Plan

[Memory](../../../memory-tool/docs/agents/tools/memory/README.md) searches documents and conversations and saves notes. [Scheduler](../../../scheduler-tool/docs/agents/tools/scheduler/README.md) delegates tasks and schedules messages.

## Ask About Local Link

[Link MCP](../../../mcp/docs/agents/tools/mcp/README.md) offers Local Link's
commands as tools, so your agent can read the offline manual, inspect its
status, and ask before it changes anything. Link MCP is off by default,
and the Onboarding ready-made agent comes with it on.
Any other agent or client that speaks the Model Context Protocol (MCP) can add it as a server
too.

## Manage an Agent’s Tools

Add or remove an agent’s tools, review the grants they request, and list
what the agent can use in
[Manage Tools](../../../../agent/docs/agents/tools/use/README.md). Each tool's
page owns that tool's detailed tasks and limits.

## Compare Tools and Providers

[Tool Details](more/README.md) compares harness support, explains managed
namespaces, and records why providers keep separate policies. Read the
[guide](more/guide.md) to choose tools and see their namespaces, and
[Decisions](more/decisions.md) to see why tools share one design.
