# Cloud

Cloud connects your cloud accounts once, so Local Link's buckets and
boxes can use them. The cloud module owns the accounts, and each cloud
adapter answers the same requests from it.

## Docs

- [Cloud Module](cloud/README.md): The cloud module (`lnk-cloud`) connects your Amazon Web Services and Google Cloud accounts once, for every part of Local Link that uses them
