# Compute

Compute holds the modules that give your agents machines. The box module
makes them in your own cloud accounts, and the env module sets them up.

<!-- docs-tree:start -->

## Docs

- [Box Module](box/README.md): The box module, `lnk-box`, makes machines in your own cloud accounts that run `lnk`
- [Environment Module](env/README.md): The env module, `lnk-env`, sets up machines from reviewed environment files
