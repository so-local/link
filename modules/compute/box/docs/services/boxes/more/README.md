# More

> Understand Box Interfaces and Contracts

An adapter implements the operations behind the box commands. The
[Interface](protocol.md) describes those operations, and
[Machine Inputs](../../../../contract/docs/services/boxes/more/contract.md)
defines the types they exchange. Read these pages when you write an
adapter. For a box task, start with the [Boxes](../README.md) page.
