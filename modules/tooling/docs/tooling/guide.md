# Tooling Overview

**What Link runs around your agents: what each agent costs, and these
docs offline.** Each is a module of its own. The
[Sandbox](../../../security/sandbox/docs/security/sandbox/README.md) every
agent runs in is under Security.

```sh
lnk measure
lnk man security/sandbox
```

## What Each Agent Costs

See what each of your agents costs you as it happens, including memory,
CPU, tokens and spend. It records numbers only, never a message, prompt,
file, tool argument or answer. See
[Measure](../../measure/docs/tooling/measure/README.md).

## These Docs, Offline

[`lnk man`](../../manual/docs/tooling/manual/README.md#manual) browses this documentation in the terminal, the same topics
as the website. See [Manual](../../manual/docs/tooling/manual/README.md).
