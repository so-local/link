# Artifact

Artifact downloads pinned files, verifies each one, and keeps them in a shared cache of bounded size.

## Docs

- [Artifact](docs/more/libraries/files/artifact.md): `link-artifact` caches immutable downloads by SHA-256, so installers can reuse verified bytes across modules and checkouts
