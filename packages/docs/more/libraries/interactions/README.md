# Questions and Effects

> Coordinate Decisions Before Applying Changes

[Interactions](../../../../interactions/docs/more/libraries/interactions/interactions.md)
coordinates questions, answers, and their effects through its
[shared contract](../../../../interactions/contract/docs/more/libraries/interactions/interactions/contract.md).
Use Interactions when an operation must wait for a person's decision.

## Authorization Rules

[Control Rules](../../../../controls/docs/more/libraries/interactions/controls.md)
and [Approval Rules](../../../../approvals/docs/more/libraries/interactions/approvals.md)
explain two distinct authorization checks. The entry points of both make the
policy explicit before a caller performs a protected operation.
