# Runtime and Communication

> Connect Commands to Processes and Services

[Runtime](../../../../runtime/docs/more/libraries/runtime/runtime.md) provides
an asynchronous runtime to synchronous entry points.
[Service Contract](../../../../service/docs/more/libraries/runtime/services.md)
defines managed services and their process protocol, including the
[Program Exchange](../../../../service/docs/more/libraries/runtime/services/exchange.md)
used to replace a running executable.

## Requests and Output

[Fetch](../../../../fetch/docs/more/libraries/runtime/fetch.md) supplies shared
HTTP behavior, and [API Client](../../../../api/docs/more/libraries/runtime/api-client.md)
provides typed request and response helpers.
[Format](../../../../format/docs/more/libraries/runtime/format.md) turns
results, failures, and next steps into output for people and programs.

## Text From Third Parties

[Untrusted Content](../../../../untrusted/docs/more/libraries/runtime/untrusted.md)
fences every page, file, document and program output a tool
hands its model, so the model can tell what a third party wrote from
what the tool and the owner say.
