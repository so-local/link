# Types and Boundaries

> Declare Interfaces and Stable Identities

Build an interface from typed declarations before adding callers.
[Component Metadata](../../../../component/docs/more/libraries/types/component-metadata.md)
describes commands and capabilities, while
[Specifications](../../../../spec/docs/more/libraries/types/specifications.md)
binds configuration files and field flags to the same reader.

## Destinations and Identity

[Workplace](../../../../workplace/docs/more/libraries/types/workplace.md)
resolves where a command runs. [Stable IDs](../../../../id/docs/more/libraries/types/id.md)
and [Principal](../../../../principal/docs/more/libraries/types/principal.md)
name resources and the identities that act on them.
[Version](../../../../version/docs/more/libraries/types/version.md) owns
version types shared by release consumers.
