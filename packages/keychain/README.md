# Keychain

`link-keychain` gives programs shared access to the macOS Keychain, and it stores secrets in private files on other machines.

<!-- docs-tree:start -->

## Docs

- [Keychain](docs/more/libraries/files/keychain.md): `link-keychain` saves secrets in the macOS Keychain through Apple's `security` tool on a Mac, and in private files on other machines
