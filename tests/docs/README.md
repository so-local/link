# Docs Checks

The docs checks read every page once and check links, headings, limits, and READMEs together.

<!-- docs-tree:start -->

## Docs

- [Writing Docs](docs/more/developing/documentation/writing-docs.md): How a page, README or guide is written and checked: the rules the docs checks hold every page to, and the limits they read
- [Docs Rules](docs/more/developing/documentation/docs-rules.md): Every rule the docs checks hold a page, README or source file to, by its id, so a writer sees each rule and its limit before a check fails
- [Writing Hooks](docs/more/developing/documentation/hooks.md): A hook is the one line under a section's plain title
- [Documentation Navigation](docs/more/developing/documentation/navigation.md): The documentation writer maintains README indexes from the pages beneath them, so readers can follow links from the repository's root without opening a file browser
- [Docs Code Checks](code/README.md): `link-docs-check-code` checks documentation examples and inventories against the command parsers, types, and declarations Local Link releases
  - [Docs Code Checks](code/docs/more/developing/documentation/checks.md): `link-docs-check-code` checks documentation against the code Link releases
