# Shared Flower Geometry

Shared Flower Geometry holds typed settings, layout, and circular-stem geometry.

## Docs

- [Flowers](../docs/more/developing/website/flowers/README.md): Render a configurable animated sunflower or a field background

## Code

- [`field.ts`](field.ts): Seeded placement, wind and pointer response
- [`geometry.ts`](geometry.ts): Circular arcs and vector shapes
- [`settings.ts`](settings.ts): Props, defaults and validation
